Built from NHS England's monthly Referral to Treatment (RTT) "Full CSV" data extract, filtered to Incomplete Pathways (the current waiting list) for the ~135 acute NHS trusts in England (a maintained reference list, since NHS's raw data doesn't tag provider type — mergers/renames may occasionally need a manual update). Median wait is estimated by linear interpolation across NHS's published weekly waiting bands. This dashboard refreshes automatically each month after NHS England publishes new figures.
